# 2.4.0 to 2.5.0

This document describes the upgrade instructions from `2.4.0` to `2.5.0`.

## Mapping LDAP groups to PlanDev roles for deployments using CAM SSO ([#1279](https://github.com/PlanDev/plandev/issues/1279))

The DEFAULT_ROLE environment variable in plandev-gateway is now a list of strings, previously only a single value was allowed. See here for more details https://nasa-ammos.github.io/plandev-docs/deployment/advanced-sso/#setting-default_roles
