# Sequencing

PlanDev's Phoenix editor provides a sequence development environment within PlanDev. Author sequences and adapt PlanDev to fit your needs:

- Start using Phoenix out of the box with the [SeqN](/plandev-docs/sequencing/seqn) authoring language and the [SeqJSON](https://github.com/NASA-AMMOS/seq-json-schema) interchange format.
- Leverage the [editor adaptation](/plandev-docs/sequencing/adaptation) to configure additional languages or implement support for your own.
- Use [PlanDev Actions](/plandev-docs/sequencing/actions) for external integrations.
